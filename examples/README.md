# Example tables for Bring a CSV

None of these are used by the demos. Each runs live on your own key.

| File | Rows | Predict | Kind | Split | Source |
|---|---|---|---|---|---|
| `breast_cancer.csv` | 569 | `diagnosis` | yes/no | random rows | UCI Wisconsin diagnostic breast cancer, as shipped with scikit-learn |
| `diabetes.csv` | 442 | `progression_one_year` | a number | random rows | Efron et al. (2004) diabetes data, as shipped with scikit-learn (`scaled=False`) |
| `seattle_weather.csv` | 1,461 | `weather` | one of 5 | by `date` | NOAA daily weather for Seattle 2012-2015, as shipped with vega-datasets |
