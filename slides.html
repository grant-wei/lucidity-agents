The problem

A good ML answer is a whole workflow

Split the data. Set a baseline. Try several kinds of model. Tune each. Score them on the same test rows. Explain the winner.

  • By hand, a data scientist's afternoon
  • With a coding agent, faster, but a wall of code and logs, usually one model, and its own word on the score

Who has it

Managers, analysts and students with a table and a question. They want a real answer in minutes, and they can't read a pipeline to check it.

What's new

The whole workflow, in plain sight

1

Orchestrated

One upload becomes a plan. Up to 10 model families get their own agent and run in parallel. You make one choice.

2

Easy to follow

A plan you approve, a live race, a leaderboard, one plain sentence per round, and a headline on what won.

3

Honest scores

Agents never see the test rows. The goal is to beat plain regression, not the weak starting model.

Colab's agent leaves you reading notebook cells. AutoGluon is fast but a black box. DataRobot does both at a reported $212k a year.

Two cuts that didn't hurt

  • Small model. Same table on Claude Haiku cost $1.28. On gpt-6-luna, $0.013. 96× cheaper, same score.
  • Prompt caching. 83% of input tokens cached. $0.42 instead of $1.58 across all runs.
Safety

Every guard has a test. 32 of 32 pass.

  • Agents can't see test scores
  • Editing the scorer or data fails the round
  • Only test runners can run. rm -rf, curl | sh refused
  • $1 cap per run, 120 calls an hour breaker
  • Keys redacted before any prompt
  • Plans wait for the owner
